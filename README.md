# Portfólio Pessoal & GitHub Foundations

Repositório de aplicação prática desenvolvido durante a trilha **GitHub Foundations** (Microsoft Learn) para a disciplina de Design Profissional.

## Objetivo
Consolidar conhecimentos em controle de versão distribuído e colaboração em projetos digitais, mantendo um histórico limpo e rastreável de entregas.

## Fluxo e Práticas Aplicadas
- **Versionamento Semântico:** Uso de commits atômicos e mensagens padronizadas (`Conventional Commits`).
- **Isolamento de Tarefas:** Desenvolvimento em *feature branches* (`feat/*`) separadas da branch principal (`main`).
- **Integração Contínua de Código:** Abertura, revisão e *merge* formal via *Pull Requests* (PR).
- **Documentação Técnica:** Estruturação clara em Markdown para facilitar a leitura e manutenção do projeto.

## Estrutura do Repositório
```text
├── README.md   # Documentação principal e visão geral do projeto
└── notas.md    # Registro de etapas e validação do fluxo Git
```
